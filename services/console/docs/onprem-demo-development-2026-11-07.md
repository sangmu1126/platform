# 워크로드 지도·보안 대응 UI 인수 기록

## 변경 목적

터미널에서 한 번 실행한 결과를 보여주는 수준에서, 기존 Sova UI로 실제 시험을
준비하고 승인·대응·정리한 뒤 반복할 수 있도록 확장했다. 운영 플랫폼 승인이나
게이트를 우회하는 프리패스는 만들지 않았다.

## 코드 기준

| 구성 | 기준 |
|---|---|
| 실제 실행 도구와 개인 supervisor | Sova `6665feb3dca2a8c18d2a187215bb2d202b77c1aa` |
| 재사용 security 계약·Guard | `4d93137416ef947e9fc3924403c7a9580f50455c` |
| UI 연결 기능 | 콘솔 `2c87ae5a`·`6bf0e330` |
| 시연 후 문구 정리 | 콘솔 `6630b664d99a0d05e9c4564fe5d919f40cdcdc04` |

문서 커밋과 위 실행 소스, 클러스터의 실제 imageID를 구분한다. 개인 설정에는
소스 SHA와 접속 도구·프로필 해시를 고정했고, 변경되면 새 시험을 거부한다.

## 실제 브라우저 인수

등록된 온프렘 RKE2에서 Chromium으로 다음 버튼을 눌러 검증했다.

```text
실제 시험 준비 → 정상 HTTP 관측·실제 UID 다섯 개 표시
→ 설정 위반 주입·대응 실행
→ 원본 격리 → 대체 기동 → 대체 HTTP 검증 → 시험 주소 Green 전환
→ 시험 종료·자원 정리
→ 다시 준비 → 다른 UID의 새 시험 → 종료·정리
```

- 첫 시연의 네 효과가 모두 실제 확인됐고 전환·복구 관측을 수신했다.
- 다음 준비에서는 원본 API UID가 달랐다. 이전 결과를 다시 정상으로 발행한 것이 아니다.
- JavaScript 오류 0건, 기존 Sova sidebar 한 개를 확인했다.
- 브라우저 변경 요청은 시연 전용 `/__demo/action` 다섯 건뿐이었다.
  `/v1` 운영 승인·실행 경로에는 변경 요청을 보내지 않았다.
- 첫 준비 약 26초, 대응 실행 약 169초를 관측했다. 종료 요청부터 정리 확인까지
  약 53초였다. 해당 환경의 한 번 실측이며 다음 실행 시간을 보장하지 않는다.
- WebKit에서도 종료 기록·실제 노드 다섯 개·동의 후 재준비 활성화와 기존 UI를 확인했다.
  이 검사는 실제 클러스터를 변경하지 않았으며, 전체 대응 실행은 Chromium으로 확인했다.
- 별도 API 조회에서 두 시험의 namespace 여섯 개가 모두 없음을 확인했다.
  기존 `target-dev` Deployment 다섯 개의 UID·generation·Ready도 이전 기준과 같았다.
- 자원 정리 후 개인 실행 파일로 서버를 다시 열고 인증된 화면·종료 기록·재준비
  가능 상태를 확인했다. 재기동 과정에서는 클러스터 자원을 만들지 않았다.

## 구현 경계와 검증

- 개인 콘솔 세션, 정확한 Origin, CSRF, 요청 ID와 현재 시험·계획을 검사한다.
- 준비 중 중복 실행을 거부하고, 같은 요청의 재호출은 두 번째 워커를 만들지 않는다.
- 허용 동작은 고정된 준비·응답·정리뿐이다. 브라우저에서 명령·이미지·namespace를 받지 않는다.
- 워커는 응답 승인의 HMAC 도메인·소스 SHA·계획·만료를 확인한다.
- 새 응답 승인은 최신 수집 근거와 최대 5분·시험 종료 기한으로 결속한다.
  기존 실행의 승인을 연장하지 않으며 전체 시험은 최대 8분이다.
- 기존 효과 원장과 Guard·UID 검사·실제 readback을 유지한다.
- 정리 불확실 상태에서는 새 시험을 막는다. 운영 API의 변경 경로는 계속 닫혀 있다.
- Sova 시험·효과 원장 회귀 40개, 콘솔·인증·기존 workload 계약 시험 49개 통과.
- Ruff·JavaScript 문법·변경 범위의 비밀 검사 통과.

이 인수는 통제된 설정 위반과 전용 무상태 HTTP 자원에 한정한다. 일반 공격 탐지,
운영 앱·DB의 무중단 이전, 전 방향 격리, T10/T19 제품 인수를 완료한 결과로 확대하지 않는다.

## 근거와 실행 방법

비공개 근거 폴더 이름은 `validation/onprem-ui-demo-20261107/`다.
`ui-evidence.private.json`, `actual-ui-response.png`, `webkit.private.json`, 실제 API의
정리 확인 결과를 연결한다. 각 실행의 효과 원장·UID·관측·서명·정리 결과는 개인
`onprem-demo/session-*/state/`에 보존한다. 공개 문서에는 접속 주소·쿠키·키를 복사하지 않는다.

개인 로컬 실행 파일로 서버와 일회용 접속 창을 함께 열 수 있도록 준비했다.
실행 조건과 버튼별 진행은 [시연 순서](onprem-demo-runbook.md)를 따른다.
